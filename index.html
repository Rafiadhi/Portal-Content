Hapus portal?

Kotak akan dihapus dari halaman ini.

Bagikan ke semua orang

Perubahan tadi baru tersimpan di browser ini. Supaya orang lain yang membuka link GitHub-mu juga melihatnya:

  1. Klik Unduh portals.js di bawah.
  2. Di GitHub, buka repo-mu, pilih Add file → Upload files, taruh portals.js satu folder dengan index.html (ganti file lama), lalu klik Commit.
  3. Tunggu sekitar 1 menit, lalu muat ulang halaman (Ctrl + F5).
